Macro Library inplacecalculator

Calculator buttons that reduce a fraction selected inside an answerbox. Version 1.0, Sept. 14, 2026

  • inplacecalculator
  • inplacecalc

Both macros place a button. Select part of an expression in an answerbox and click any of these buttons, or press ctrl-enter, and the selection is replaced by its reduced value. Selecting "1/2+1/3" in "x+1/2+1/3" gives "x+5/6".

No replacement is made unless the selection is a rational expression: digits, unary -, the operators ^ * / + -, and ( ) [ ], with ^ limited to the integer powers -2 through 2. Nothing happens if the selection is undefined, such as "1/(1-1)", or if the replacement would change the value of the answer. Selecting "2+1/3" in "x+1/2+1/3" makes no replacement, because "x+1/7/3" is a different expression. Replacements are made only in MathQuill answerboxes.

inplacecalculator

inplacecalculator()

A button labelled "Ctrl ↵" with an input box before it and an output box after it. Besides replacing a selection, it shows the selected text in the input box and the reduced value in the output box. With nothing selected it works as a plain fraction calculator: type "1/2+1/3" in the input box, click the button, and "5/6" appears in the output box. Ctrl-enter replaces a selection but leaves the two boxes alone.

Examples
Common Control
loadlibrary("inplacecalculator")
$calculator = inplacecalculator()

Question Text
$calculator
$answerbox

inplacecalc

inplacecalc()

A small button with no input or output boxes. It replaces a selection exactly as the button above does, but puts nothing in any box. Any number of these may be placed in a question, usually just ahead of the answerbox they serve. To replace the default label "#" with say, "%", write inplacecalc("%") instead of inplacecalc().

Examples
Common Control
loadlibrary("inplacecalculator")
$calc = inplacecalc()

Question Text
[AB0]
$calc [AB1]
$calc [AB2]
