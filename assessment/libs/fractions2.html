Macro Library fractions2

Operations on fractions. If an expression expr can simplify to a fraction, simplifyfraction(expr) returns the reduced fraction. Version 1, Oct. 3, 2026, Dale Myers

An expression expr may use 0-9, pi, + - * / // ^ ( ) [ ] { }, unary minus and implicit multiplication, with ^ limited to the powers -5 to 5. When expr does not simplify to a fraction n/m or (n pi)/m, simplifyfraction, dispsimplifyfraction, fractionnumerator, fractiondenominator and makerepeatingdecimal return "DNE", and isreducedfraction returns false. Each echoes one of these warnings:

  • "division by zero"
  • "powers other than -5 to 5 are not accepted"
  • "% is not an accepted character", for the first character not accepted (here %)
  • "numbers are too large"
  • "this doesn't make a fraction", otherwise

simplifyfraction

simplifyfraction(expr)
Returns the reduced fraction which is equivalent to expr, or "DNE" if none. Negative fractions are written -1/2, not (-1)/2 or 1/(-2). A denominator of 1 and a coefficient 1 on pi are dropped.
If every division in expr is //, the result uses //; otherwise it uses /. With /, a multiple of pi is put in parentheses, (3pi)/4, so that `(3pi)/4` renders as a single fraction.
Examples 
simplifyfraction("6/3") = "2"
simplifyfraction("1/(-2)") = "-1/2"
simplifyfraction("6/4") = "3/2"
simplifyfraction("6//4") = "3//2"
simplifyfraction("1/2-1/3") = "1/6"
simplifyfraction("1/2-1//3") = "1/6"
simplifyfraction("1//2-1//3") = "1//6"
simplifyfraction("6pi/4") = "(3pi)/2"
simplifyfraction("-6pi/4") = "-(3pi)/2"
simplifyfraction("6pi//4") = "3pi//2"
simplifyfraction("1pi/4") = "pi/4"
simplifyfraction("pi/4+6pi//4") = "(7pi)/4"
simplifyfraction("1/[1/2-1/3]") = "6"
simplifyfraction("1/{1/2-1/3}") = "6"
simplifyfraction("1/(3/(1-4))^2") = "1"
simplifyfraction("6/0") = "DNE" with the warning "division by zero"
simplifyfraction("6^3") = "DNE" with the warning "powers other than -2,-1,0,1,2 are not accepted"
simplifyfraction("6x/3") = "DNE" with the warning "x is not an accepted character"
simplifyfraction("6)((3") = "DNE" with the warning "this doesn't make a fraction"
simplifyfraction("0^0") = "DNE" with the warning "this doesn't make a fraction"

dispsimplifyfraction

dispsimplifyfraction(expr)
Returns " `simplifyfraction(expr)`", a space followed by simplifyfraction(expr) in backticks, so it is rendered by AsciiMath.
Examples 
dispsimplifyfraction("6/4") = " `3/2`"
dispsimplifyfraction("-6pi/4") = " `-(3pi)/2`"
dispsimplifyfraction("1//2-1//3") = " `1//6`"

fractionnumerator

fractionnumerator(expr)
Returns the numerator of simplifyfraction(expr). If pi is involved, it is the coefficient of pi in the numerator.
Examples 
fractionnumerator("6/4") = 3
fractionnumerator("3/(-12)") = -1
fractionnumerator("3pi/2") = 3

fractiondenominator

fractiondenominator(expr)
Returns the denominator of simplifyfraction(expr), which is always positive.
Examples 
fractiondenominator("4/2") = 1
fractiondenominator("4/(-12)") = 3
fractiondenominator("3pi/6") = 2

isreducedfraction

isreducedfraction(expr)
Returns true iff expr is a reduced fraction simplified as much as possible. -(1/2), (-1)/2 and 1/(-2) are considered reduced fractions; (-1)/(-2) is not.
Examples 
isreducedfraction("4") = true
isreducedfraction("4/5") = true
isreducedfraction("4/(-5)") = true
isreducedfraction("-pi") = true
isreducedfraction("(4pi)/3") = true
isreducedfraction("4(pi/3)") = true
isreducedfraction("(-4)/(-5)") = false
isreducedfraction("4/6") = false
isreducedfraction("6/1") = false
isreducedfraction("2*3") = false
isreducedfraction("--4") = false
isreducedfraction("1pi/2") = false
isreducedfraction("1+pi") = false with the warning "this doesn't make a fraction"
isreducedfraction("2x/3") = false with the warning "x is not an accepted character"

makerepeatingdecimal

makerepeatingdecimal(expr)
Returns the repeating decimal of the fraction produced by simplifyfraction(expr), in AsciiMath notation without a leading 0, e.g., 1.0bar(35) or .25.
Examples 
makerepeatingdecimal("1/4") = ".25"
makerepeatingdecimal("1/3") = ".bar(3)"
makerepeatingdecimal("-13/3") = "-4.bar(3)"
makerepeatingdecimal("301/300") = "1.00bar(3)"
makerepeatingdecimal("15/7") = "2.bar(142857)"
makerepeatingdecimal("pi/2") = "DNE" with the warning "pi fractions do not have repeating decimals"

repeatingdecimal2fraction

repeatingdecimal2fraction(repeatdec)
Returns the fraction with the same value as repeatdec, a decimal written in AsciiMath notation such as "-4.bar(3)" or "4.33".
Any other input returns "DNE" and echoes the input followed by "should be like -2.33 or 2.1bar(33)".
Examples 
repeatingdecimal2fraction("-.33") = "-33/100"
repeatingdecimal2fraction("4.33") = "433/100"
repeatingdecimal2fraction(".bar(3)") = "1/3"
repeatingdecimal2fraction("-4.bar(3)") = "-13/3"
repeatingdecimal2fraction("1/3") = "DNE" with the warning "1/3 should be like -2.33 or 2.1bar(33)"

randfraction

randfraction(denoms, min, max, [symbol])
Returns a random reduced fraction between min and max whose denominator is in the array denoms, or "DNE" if there is none.
Parameters
  • denoms: an array of possible denominators, e.g., [2,3,5,7]. The denominator of the result is always one of denoms. To include integers, add 1 to denoms.
  • min: a decimal or integer.
  • max: a decimal or integer. Note min and max are for the value of the fraction, not the numerator.
  • symbol: optional. Can be '/', '//', 'pi/' or 'pi//', with default '/'. These give fractions like '2/5', '2//5', '(2pi)/5', '2pi//5'. The symbol may not appear in a result like '0'.
Examples 
randfraction([2,3,5,7], 0, 1) could be '2/5' but not '0' or '1'
randfraction([1,2,3,5,7], 0, 1) could be '2/5', '0' or '1'
randfraction([4], 1, 9) could be '23/4' but not '9/2'
randfraction([2,3,5,7], 0, 1, '//') could be '2//5'
randfraction([2,3,5,7], 0, 1, 'pi/') could be '(2pi)/5'
randfraction([2,3,5,7], 0, 1, 'pi//') could be '2pi//5'
randfraction([1], .3, .6) = "DNE"
randfraction([1,2,3,4], 0, -1) = "DNE"
randfraction([4], .3, .6) = "DNE"

randfractions

randfractions(denoms, min, max, n, [symbol], [order])
Returns an array of n random reduced fractions, chosen as in randfraction, or ["DNE"] if the conditions cannot be met.
Parameters
  • denoms: an array of possible denominators, e.g., [2,3,5,7]. The denominator of the result is always one of denoms. To include integers, add 1 to denoms.
  • min: a decimal or integer.
  • max: a decimal or integer. Note min and max are for the value of the fraction, not the numerator.
  • n: the number of fractions to return.
  • symbol: optional. Can be '/', '//', 'pi/' or 'pi//', with default '/'. These give fractions like '2/5', '2//5', '(2pi)/5', '2pi//5'. The symbol may not appear in a result like '0'.
  • order: optional. Can be '', 'inc' or 'dec', with default '' (no ordering). Values may repeat, so 'inc' and 'dec' are not always strict.
Examples 
randfractions([2,3,5,7], 0, 1, 3, 'pi/') could be ['(3pi)/5', '(2pi)/7', 'pi/2']
randfractions([2,3,5,7], 0, 1, 3, 'pi//') could be ['3pi//5', '2pi//7', 'pi//2']
randfractions([2,3,5,7], -1, 1, 4, '/', 'inc') could be ['-6/7', '2/7', '1/2', '3/5']
randfractions([2,3,5,7], -.999, .999, 4, '/', 'dec') could be ['3/5', '1/2', '2/7', '-6/7']
randfractions([2,3,5,7], 1, 0, 2) = ["DNE"]

diffrandfractions

diffrandfractions(denoms, min, max, n, [symbol], [order], [diffdenoms])
Returns an array of n different random reduced fractions, or ["DNE"] if there are fewer than n. Otherwise the same as randfractions.
Parameters
  • denoms: an array of possible denominators, e.g., [2,3,5,7]. The denominator of the result is always one of denoms. To include integers, add 1 to denoms.
  • min: a decimal or integer.
  • max: a decimal or integer. Note min and max are for the value of the fraction, not the numerator.
  • n: the number of fractions to return.
  • symbol: optional. Can be '/', '//', 'pi/' or 'pi//', with default '/'. These give fractions like '2/5', '2//5', '(2pi)/5', '2pi//5'. The symbol may not appear in a result like '0'.
  • order: optional. Can be '', 'inc' or 'dec', with default '' (no ordering). Values may repeat, so 'inc' and 'dec' are not always strict.
  • diffdenoms: options, default false. Set true if you want each fraction returned to have a different denominator, not just a different fraction value. Note that if n is larger than the set of denominators, you may get repeats.
Examples 
diffrandfractions([2,3,5,7], 0, 1, 3, 'pi//') could be ['3pi//5', '2pi//7', 'pi//2']
diffrandfractions([2,3,5,7], 0, 1, 3, '/', 'inc') could be ['2/7', '1/2', '3/5'] or ['2/7', '3/7', '4/5']
diffrandfractions([2], 0, 1, 4) = ["DNE"]
diffrandfractions([2,3,4], 0, 1, 3, '/', '', true) could be ['1/2','1/3','3/4'], but not ['1/2','1/3','2/3']
